# 🧺 LinenGrass Laundry ERP System

**LinenGrass** is a robust, modular **Laundry ERP (Enterprise Resource Planning)** system built to streamline operations for industrial laundry services. It manages inventory, wash cycles, fulfillment, trip logistics, vendor operations, and hotel orders with seamless API integrations and a clean, user-friendly interface.

> ⚙️ Tech Stack: React (Vite) + Material UI + Spring Boot + MySQL

---

## 🌟 Features

### 🏨 Hotel Management
- Manage hotel agreements with flexible and fixed billing options
- Generate and complete hotel orders
- Track order status and order reference history

### 🧼 Wash Requests & Fulfillments
- Create wash requests from scheduled pickups
- Auto-fetch soiled items grouped by product
- Track washed quantities and fulfillment records

### 📦 Inventory Management
- Real-time inventory summary with warehouse grouping
- Reservation and inward processing
- Drilldown views with Drawer-based UI

### 🚛 Trip & Logistics
- Schedule trips with delivery and pickup visits
- Mark delivery and pickup requests as completed
- Populate actual items collected using smart UI prompts

### 🧾 Reporting & Utilities
- Dashboard with visual KPIs (coming soon)
- Mock-to-API transition for smooth staging
- Modular service architecture with centralized API integration

## 🚀 Getting Started

### 🔧 Frontend Setup

```bash
# 1. Clone the repository
git clone https://rohitprofc-admin@bitbucket.org/linengrass/linengrass-laundry-erp.git

# 2. Navigate into the frontend
cd linengrass-laundry-erp/
```
